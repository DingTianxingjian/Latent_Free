Figures for the paper.  Regenerate both with

    envs/univla_vla/bin/python acdc_la/figures/make_paper_figures.py

Every number lives in the DATA block at the top of that script, tagged `[real]` (with its LEDGER date) or
`[PLACEHOLDER]`.  Palette validated with the data-viz validator (light surface, categorical, CVD-safe); the one slot
below 3:1 contrast carries a direct value label as relief.  PDFs are vector with embedded Type-42 fonts.
